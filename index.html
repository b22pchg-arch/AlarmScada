Hướng dẫn sử dụng nhanh

  1. Xuất Alarm Summary từ SCADA sang .xlsx hoặc .csv.
  2. Mở file HTML này trên máy offline, chọn file dữ liệu.
  3. Kiểm tra phần nhận diện cột. Nếu sai, chọn lại các cột: thời gian, message, thiết bị, trạng thái...
  4. Tab Tổng quan: xem thiết bị nhiều alarm, alarm lặp, phân bố theo giờ.
  5. Tab Trình tự Alarm: lọc theo mã thiết bị, từ khóa hoặc thời gian.
  6. Tab Phân tích thiết bị / MC: nhập mã như 374 để kiểm tra có lệnh trip/cắt, có phản hồi mở hay không, và các alarm khóa/liên động/mạch trip đi kèm.
Lưu ý: Đây là công cụ hỗ trợ phân tích Alarm Summary, không thay thế SOE/Record rơle/sơ đồ nhị thứ. Kết luận “MC không tác động” cần đối chiếu thêm tín hiệu 52a/52b, SOE rơle, nguồn DC, mạch trip, cuộn cắt, SF6/lò xo tích năng, Local/Remote và liên động.
